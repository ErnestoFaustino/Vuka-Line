# Vuka Line

### Painel de Divulgação de Oportunidades de Estágio

O **Vuka Line** é uma plataforma web desenvolvida com o objetivo de facilitar a divulgação, pesquisa e candidatura a oportunidades de estágio profissional. A plataforma estabelece uma ligação entre estudantes que procuram a primeira experiência no mercado de trabalho e empresas que pretendem encontrar jovens talentos.

Através de uma interface simples, intuitiva e acessível, o sistema permite que as empresas publiquem e gerenciem oportunidades de estágio, enquanto os estudantes podem consultar vagas disponíveis, visualizar os seus detalhes e submeter candidaturas diretamente pela plataforma.

O projeto também disponibiliza um painel administrativo para gerir utilizadores, empresas, estudantes e oportunidades de estágio, garantindo uma melhor organização e gestão das informações.

### 🎯 Objetivo do Projeto

Contribuir para a aproximação entre instituições de ensino, estudantes e empresas, tornando o processo de divulgação e candidatura a oportunidades de estágio mais simples, organizado e eficiente.

### 💡 Principais Funcionalidades

- **Estudantes:** criação de conta, consulta de vagas e submissão de candidaturas.
- **Empresas:** gestão de perfil, publicação e administração de oportunidades de estágio.
- **Administradores:** gestão de estudantes, empresas, utilizadores e vagas.
- **Candidaturas:** acompanhamento e gestão das candidaturas submetidas.

### 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- PHP
- MySQL
